BISCOTTI BIRTHDAY WEBSITE

Put your ten JPG photos in assets/ using:
memory-1.jpg through memory-10.jpg

The gallery uses object-fit: contain so each image keeps its complete composition and is not cropped to fill the frame. It is a swipe/button-style memory album with 10 configured slots.

This package currently includes the five photos available in the chat as memory-1.jpg through memory-5.jpg. Add your other five as memory-6.jpg through memory-10.jpg.

Optional music: put your own permitted audio file beside index.html and name it music.mp3.
